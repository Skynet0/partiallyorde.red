Potential Projects

Are you an undergraduate interested in doing research or a project with me? Here's some topics and areas that I work on or are interesting to me.

Please note that nearly all of these will involve some element of pedagogy or cirruculum development; as such, I can unfortunately only take on Caltech undergraduates at this time.

CS 11

Qualifications: CS 3x; CS 24 and CS 99 recommended

A CS 11 is a 3-unit pass-fail course intended to teach a specific programming language or paradigm. The audience for these courses is undergraduates who want to use the language in interviews, internships, personal projects, or research.

I am actively working on developing CS 11s for:

  • C++, focusing on modern features and safety

I am considering CS 11s for:

  • Golang, focusing on parallelism (goroutines) and distributed systems

Database Systems

Qualifications: CS/IDS 121 in Winter 2026 or later

I teach the database systems course, in which students implement pieces of a relational database engine.

We are slowly working on adding features to the database. Some of them would be future projects; some would be helpful pedagogically; others are just interesting. If you have a suggestion, please let me know!

Examples:

  • JDBC with PostgreSQL wire protocol
  • TPC-H compatibility
  • Database internals visualizations
  • ARIES checkpointing
  • Optimistic MVCC

Modern Web(sites)

Qualifications: CS 3x; CS 99 recommended

I'm designing a course about how the modern web(site) works. This is not a course about learning how to make a full-stack web application or frontend design or similar. Instead, assignments would include implementing pieces of a web browser, implementing React, or implementing a web framework; among other possibilities.
